# Blue Whale Game — Anime Video Website

This archive contains the complete React/Tailwind source for the anime-themed video website.

## Included

The site opens with the supplied video, uses the title “Blue Whale Game,” and includes a **Download Blue Whale** control. That control downloads the supplied MP4 awareness video only. No APK is included or linked.

## Run locally

Install dependencies with `pnpm install`, then start the development server with `pnpm dev`. The production checks are `pnpm check` and `pnpm build`.

## Asset note

The video and generated visual assets are referenced through project storage URLs in `client/src/pages/Home.tsx` and remain available through the associated Manus project lifecycle.
